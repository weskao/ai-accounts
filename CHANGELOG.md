## [0.1.0] - 2026-08-23

### Added

- Standalone `ai-accounts` package and `ai_accounts` Python library.
- Profile management for Codex, Claude Code, Antigravity, Grok Build, and
  Mistral Vibe.
- Shared configuration, quota-aware auto-switch hooks, scheduler integration,
  notifications, and native credential-store support.
